# Nouveautés (« What's new ») — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** signaler chaque nouveauté par une icône dans la barre du haut et un chemin de points jusqu'à l'élément nouveau, encadré à l'arrivée.

**Architecture:** le catalogue des nouveautés vit dans le site (`src/frontend/src/modules/whatsnew/`) ; l'API ne
stocke, par compte, qu'une référence de version (préférence `whatsNew.baseline`) et trois horodatages par nouveauté
(`whats_new_items`). Un hook calcule les nouveautés actives et alimente trois composants : `WhatsNewDot` (point
sur un repère), `WhatsNewTarget` (cadre + « vue » à l'apparition) et `WhatsNewButton` (icône + liste).

**Tech Stack:** ASP.NET Core 10, EF Core (Pomelo), DbUp, xUnit + Moq + Testcontainers MariaDB ; React 18,
TanStack Query 5, i18next, Vitest + Testing Library.

**Spec:** `docs/superpowers/2026-10-14-whats-new-design.md` · Maquettes : https://claude.ai/artifact/Gfrqm3uK8aAH6GPuQbTGv9

## Global Constraints

- Identifiant de nouveauté : `^[a-z0-9-]{1,64}\z` (serveur) / `/^[a-z0-9-]{1,64}$/` (site). Repère : `<zone>:<nom>`, littéral dans le code.
- Version : `^\d{1,5}\.\d{1,5}\.\d{1,5}(-dev)?\z` ; comparaison numérique `major.minor.patch`, `-dev` ignoré.
- Lot : 1 à 50 identifiants par `PUT api/WhatsNew/items`, dédoublonnés avant écriture.
- États : `shown` | `listed` | `seen` ; chaque état ne remplit sa colonne que si elle est vide ; tout état remplit aussi `first_shown_at` s'il est vide.
- Expiration : 30 jours après `first_shown_at`.
- L'API omet les champs `null` (`WhenWritingNull`) : côté client `baseline?`, `firstShownAt?`, `listedAt?`, `seenAt?` sont optionnels, jamais `null`.
- Dates renvoyées en UTC explicite (`DateTime.SpecifyKind(…, DateTimeKind.Utc)`), sinon le navigateur les lit en heure locale.
- Une migration pour la fonctionnalité, `0003_whats_new.sql`, dont chaque instruction se rejoue sans erreur (`CREATE TABLE IF NOT EXISTS`, `INSERT IGNORE`, aucun `ALTER`) ; ne jamais modifier un script livré.
- Couleurs : uniquement des tokens de rôle (`.claude/rules/frontend-theming.md`). Nouveau token `--new-dot`, contraste ≥ 3:1 sur `--rail-bg`, `--topbar-bg`, `--folders-bg`, `--surface`, `--pane-item-active-bg`, dans les 16 combinaisons palette/mode et la palette personnalisée.
- Libellés en anglais, traduction dans `locales/fr` (apostrophe `’`, U+00A0 avant `; : ? !`) ; `parity.test.ts` et `keys.test.ts` doivent rester verts. Jamais de clé passée en variable à `t()` sauf le gabarit `items.${id}.…`, couvert par le test du catalogue.
- Méthodes : 5 paramètres au plus ; pas de doublon (paramétrer plutôt que copier).
- Commentaires : seulement un pourquoi non évident, 3 lignes max.
- Commits : deux lignes max, terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, via heredoc `git commit -F -`. Ne pas pousser.
- Avant chaque commit côté API : `git checkout -- src/scotty.microservice/ApiDocumentation.xml`, puis ne réintégrer que les blocs des nouveaux membres documentés.
- Tests API : `cd src && dotnet test` (jamais `--no-build` après un nouveau fichier) ; ciblé : `cd src && dotnet test --filter "FullyQualifiedName~WhatsNew"`. Les tests MariaDB exigent Docker : s'ils sont « skipped », le dire dans le rapport.
- Tests web : depuis `src/frontend`, `npx vitest run <chemin>` ; puis `npm run typecheck` et `npm run lint`.

```sql
-- What's new: one row per account and novelty, and the version each existing account is signalled from.
-- Both statements run again safely after a failure: the table is created only if absent, rows already there are kept.
CREATE TABLE IF NOT EXISTS `whats_new_items` (
  `user_id` char(36) NOT NULL,
  `item_id` varchar(64) NOT NULL,
  `first_shown_at` datetime DEFAULT NULL COMMENT 'UTC; the 30-day expiry counts from here',
  `listed_at` datetime DEFAULT NULL COMMENT 'UTC',
  `seen_at` datetime DEFAULT NULL COMMENT 'UTC',
  PRIMARY KEY (`user_id`, `item_id`),

) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin;
```

```csharp
using System.Text.RegularExpressions;

namespace weesky.Scotty.Microservice.Models.WhatsNew;

internal static partial class WhatsNewRules
{
    public const int MaxIds = 50;

    /// <summary>The refusal for a batch of ids, or null when every id is acceptable.</summary>
    public static string? RefuseIds(IReadOnlyList<string> ids) => ids switch
    {
        { Count: 0 } => "At least one item is required",
        { Count: > MaxIds } => $"No more than {MaxIds} items at a time",
        _ when ids.Any(id => id is null || !Id().IsMatch(id)) => "Item ids are 1 to 64 lowercase letters, digits or dashes",
        _ => null
    };

    public static bool IsVersion(string? version) => version is not null && Version().IsMatch(version);

    // \z, not $: $ also matches before a final newline.
    [GeneratedRegex(@"^[a-z0-9-]{1,64}\z")]
    private static partial Regex Id();

    [GeneratedRegex(@"^\d{1,5}\.\d{1,5}\.\d{1,5}(-dev)?\z")]
    private static partial Regex Version();
}
```

```csharp
using Microsoft.EntityFrameworkCore;
using weesky.Scotty.Microservice.Data.Preferences;
using weesky.Scotty.Microservice.Models;
using weesky.Scotty.Microservice.Models.WhatsNew;

namespace weesky.Scotty.Microservice.Repositories;

internal sealed class WhatsNewStore(PreferencesDbContext context)
    : ScopedStore<WhatsNewItem>(context), IWhatsNewStore
{
    public async Task<WhatsNewState> GetAsync(Guid userId, CancellationToken cancellationToken)
    {
        var baseline = await Context.UserPreferences.AsNoTracking()
            .Where(p => p.UserId == userId && p.PreferenceKey == UserPreferences.WhatsNewBaseline)
            .Select(p => p.PreferenceValue)
            .FirstOrDefaultAsync(cancellationToken);
        var items = await Scoped(i => i.UserId == userId)
            .OrderBy(i => i.ItemId)
            .ToListAsync(cancellationToken);

        return new WhatsNewState(baseline, items);
    }

    public async Task MarkAsync(
        Guid userId, IReadOnlyCollection<string> itemIds, WhatsNewMark mark, CancellationToken cancellationToken)
    {
        try
        {
            await StampAsync(userId, itemIds, mark, cancellationToken);
        }
        catch (DbUpdateException)
        {
            // Another tab created one of these rows first; the retry finds it and only fills gaps.
            Context.ChangeTracker.Clear();
            await StampAsync(userId, itemIds, mark, cancellationToken);
        }
    }

    public async Task<bool> SetBaselineAsync(Guid userId, string version, CancellationToken cancellationToken)
    {
        if (await Context.UserPreferences.AnyAsync(
                p => p.UserId == userId && p.PreferenceKey == UserPreferences.WhatsNewBaseline, cancellationToken))
            return false;

        Context.UserPreferences.Add(new UserPreference
        {
            UserId = userId, PreferenceKey = UserPreferences.WhatsNewBaseline, PreferenceValue = version, UpdatedAt = DateTime.UtcNow
        });
        try
        {
            await Context.SaveChangesAsync(cancellationToken);
            return true;
        }
        catch (DbUpdateException)
        {
            // Another tab wrote it between the check and the insert: theirs stands.
            Context.ChangeTracker.Clear();
            return false;
        }
    }

    private async Task StampAsync(
        Guid userId, IReadOnlyCollection<string> itemIds, WhatsNewMark mark, CancellationToken cancellationToken)
    {
        var rows = await Set
            .Where(i => i.UserId == userId && itemIds.Contains(i.ItemId))
            .ToListAsync(cancellationToken);
        var now = DateTime.UtcNow;

        foreach (var id in itemIds.Except(rows.Select(r => r.ItemId)))
        {
            var row = new WhatsNewItem { UserId = userId, ItemId = id };
            Set.Add(row);
            rows.Add(row);
        }
        foreach (var row in rows) row.Stamp(mark, now);

        await Context.SaveChangesAsync(cancellationToken);
    }
}
```

```csharp
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Mvc;
using weesky.Scotty.Microservice.Models.WhatsNew;

namespace weesky.Scotty.Microservice.Controllers;

/// The caller's progress through the web app's novelties. The catalogue lives in the web app; this
/// side stores ids it has validated, three stamps per id and a baseline version written once.

    /// <param name="cancellationToken">cancellation token</param>
    /// <response code="200">Baseline (absent until written) and stamps</response>
    /// <response code="401">Not authenticated</response>
    [HttpGet]
    [ProducesResponseType(StatusCodes.Status200OK)]
    [ProducesResponseType(StatusCodes.Status401Unauthorized)]

    /// <param name="request">ids (1 to 50) and the state to stamp</param>

    /// <response code="401">Not authenticated</response>

    [ProducesResponseType(StatusCodes.Status204NoContent)]

    {
        if (request?.Ids is null || request.State is not { } state || !Enum.IsDefined(state))
            return BadRequestEnveloppe("Ids and a known state are required");

        var ids = request.Ids.Distinct(StringComparer.Ordinal).ToList();
        if (WhatsNewRules.RefuseIds(ids) is { } refusal) return BadRequestEnveloppe(refusal);

        await store.MarkAsync(AuthenticatedUser.WebmailUid, ids, state, cancellationToken);
        return StatusCode(StatusCodes.Status204NoContent);
    }

    /// <param name="request">the web app's version</param>

    /// <response code="401">Not authenticated</response>

    [ProducesResponseType(StatusCodes.Status204NoContent)]

    }
```

```ts
const parts = (version: string) => version.replace(/-dev$/, '').split('.').map(Number)

/** Negative, zero or positive as `a` is older than, the same as or newer than `b`. */
export function compareVersions(a: string, b: string): number {
  const x = parts(a), y = parts(b)
  for (let i = 0; i < 3; i++) {
    const delta = (x[i] ?? 0) - (y[i] ?? 0)
    if (delta !== 0) return delta
  }
  return 0
}
```

```ts
import type { WhatsNewContext, WhatsNewEntry } from './catalog'
import type { WhatsNewItemState, WhatsNewMark, WhatsNewState } from './types'
import { compareVersions } from './version'

const EXPIRY_MS = 30 * 24 * 60 * 60 * 1000

export interface Novelty {
  entry: WhatsNewEntry
  state?: WhatsNewItemState
  /** Published after the account's baseline. */
  fresh: boolean
  active: boolean
  unlisted: boolean
}

export function noveltiesOf(
  catalog: readonly WhatsNewEntry[], state: WhatsNewState, context: WhatsNewContext, now: number,
): Novelty[] {
  const byId = new Map(state.items.map(item => [item.id, item]))
  return catalog
    .map((entry, order) => ({ entry, order }))
    .filter(({ entry }) => entry.when?.(context) ?? true)
    .sort((a, b) => compareVersions(b.entry.version, a.entry.version) || b.order - a.order)
    .map(({ entry }) => {
      const item = byId.get(entry.id)
      const fresh = state.baseline !== undefined && compareVersions(entry.version, state.baseline) > 0
      const expired = item?.firstShownAt !== undefined && now - Date.parse(item.firstShownAt) >= EXPIRY_MS
      const active = fresh && !item?.seenAt && !expired
      return { entry, state: item, fresh, active, unlisted: active && !item?.listedAt }
    })
}

/** The server's rule, applied ahead of its answer: an empty stamp fills, a set one stays. */
export function stamp(state: WhatsNewState, ids: string[], mark: WhatsNewMark, at: string): WhatsNewState {
  const column = { shown: 'firstShownAt', listed: 'listedAt', seen: 'seenAt' } as const
  const known = new Set(state.items.map(item => item.id))
  const items = [...state.items, ...ids.filter(id => !known.has(id)).map(id => ({ id }))]
  return {
    ...state,
    items: items.map(item => ids.includes(item.id)
      ? { ...item, firstShownAt: item.firstShownAt ?? at, [column[mark]]: item[column[mark]] ?? at }
      : item),
  }
}
```

```ts
import { useEffect, useMemo } from 'react'
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query'
import { api } from '../../api.js'
import { useAppSettings } from '../../hooks/useAppSettings'
import { WEB_VERSION } from '../../lib/appVersion'
import { WHATS_NEW } from './catalog'
import { noveltiesOf, stamp } from './model'
import type { WhatsNewMark, WhatsNewState } from './types'

export const whatsNewKey = ['whatsNew'] as const

function useWhatsNewState() {
  return useQuery({
    queryKey: whatsNewKey,
    queryFn: ({ signal }) => api.getWhatsNew({ signal }),
    staleTime: 5 * 60 * 1000,
  })
}

export function useMarkWhatsNew() {
  const client = useQueryClient()
  return useMutation({
    mutationFn: ({ ids, mark }: { ids: string[]; mark: WhatsNewMark }) => api.markWhatsNew(ids, mark),
    // Optimistic, so a dot goes out the moment its novelty is reached rather than a round trip later.
    onMutate: async ({ ids, mark }) => {
      await client.cancelQueries({ queryKey: whatsNewKey })
      client.setQueryData<WhatsNewState>(whatsNewKey, old => old && stamp(old, ids, mark, new Date().toISOString()))
    },
    onSettled: () => client.invalidateQueries({ queryKey: whatsNewKey }),
  })
}

export function useWhatsNew() {
  const { data: state } = useWhatsNewState()
  const { data: appSettings } = useAppSettings()
  const { mutate } = useMarkWhatsNew()
  return useMemo(() => {
    const novelties = state && appSettings ? noveltiesOf(WHATS_NEW, state, { appSettings }, Date.now()) : []
    const active = novelties.filter(n => n.active)
    const unlisted = active.filter(n => n.unlisted)
    return {
      novelties,
      fresh: novelties.filter(n => n.fresh),
      active,
      unlistedCount: unlisted.length,
      lights: (anchor: string) => active.some(n => n.entry.path.includes(anchor)),
      targetOf: (anchor: string) => active.find(n => n.entry.target === anchor),
      markListed: () => {
        if (unlisted.length > 0) mutate({ ids: unlisted.map(n => n.entry.id), mark: 'listed' })
      },
    }
  }, [state, appSettings, mutate])
}

/** Mounted once, in AppShell: writes a new account's baseline and starts each dot's 30 days. */
export function useWhatsNewSync() {
  const client = useQueryClient()
  const { data: state } = useWhatsNewState()
  const { active } = useWhatsNew()
  const { mutate: mark } = useMarkWhatsNew()
  const { mutate: setBaseline } = useMutation({
    mutationFn: (version: string) => api.setWhatsNewBaseline(version),
    onSettled: () => client.invalidateQueries({ queryKey: whatsNewKey }),
  })

  const baselineMissing = state !== undefined && state.baseline === undefined
  useEffect(() => { if (baselineMissing) setBaseline(WEB_VERSION) }, [baselineMissing, setBaseline])

  const unshown = active.filter(n => !n.state?.firstShownAt).map(n => n.entry.id).join(',')
  useEffect(() => { if (unshown) mark({ ids: unshown.split(','), mark: 'shown' }) }, [unshown, mark])
}
```

```tsx
  const novelty = useWhatsNew().targetOf(id)
  const { mutate } = useMarkWhatsNew()
  const { state } = useLocation() as { state: { whatsNew?: string } | null }
  const ref = useRef<HTMLDivElement>(null)
  // Latched: the frame outlives the "seen" it triggers, until the page is left.
  const [framed, setFramed] = useState(false)
  const noveltyId = novelty?.entry.id

  useEffect(() => { if (noveltyId) setFramed(true) }, [noveltyId])

  useEffect(() => {
    const element = ref.current
    if (!noveltyId || !element) return
    const observer = new IntersectionObserver(([entry]) => {
      if (!entry?.isIntersecting) return
      observer.disconnect()
      mutate({ ids: [noveltyId], mark: 'seen' })
    }, { threshold: 0.5 })
    observer.observe(element)
    return () => observer.disconnect()
  }, [noveltyId, mutate])

  useEffect(() => {
    if (!framed || state?.whatsNew !== noveltyId) return
    const smooth = !window.matchMedia('(prefers-reduced-motion: reduce)').matches
    ref.current?.scrollIntoView({ block: 'center', behavior: smooth ? 'smooth' : 'auto' })
  }, [framed, state, noveltyId])

  return (
    <div ref={ref} className={framed ? 'whats-new-target is-new' : 'whats-new-target'}>
      {children}
      {framed && <span className="new-tag">{t('new')}</span>}
    </div>
  )
}
```
